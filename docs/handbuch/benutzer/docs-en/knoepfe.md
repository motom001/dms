# What buttons look like

In Ablago the shape of a button tells you what it does – without trying it out. Here you see all kinds at a glance. The pictures come straight from Ablago; if you read the manual in dark mode, they are dark too.

## Buttons { #knoepfe }

![Buttons: + New green, Save blue, Cancel and Delete with a border](bilder/knoepfe-arten.png#only-light){ loading=lazy }
![Buttons: + New green, Save blue, Cancel and Delete with a border](bilder/knoepfe-arten-dunkel.png#only-dark){ loading=lazy }

- **Filled blue – the main button:** what you mainly do here, for example **Save**. There is usually only one.
- **Green with “+” – create:** creates something new. Behind it is what you create, for example **+ Contract** or **+ New**.
- **With a border – further actions:** for example **Cancel**, **Discard** or **Download**.

## Links { #links }

![Ways: + New, Download as PDF, the links Back to the list and Help on example.org](bilder/knoepfe-wege.png#only-light){ loading=lazy }
![Ways: + New, Download as PDF, the links Back to the list and Help on example.org](bilder/knoepfe-wege-dunkel.png#only-dark){ loading=lazy }

Blue text without a border is a **link**: it takes you somewhere else – to another page in Ablago or outside – and does nothing else. Anything that does something is always a button.

## Dangerous actions { #gefahr }

![Delete at rest with a border, red with the mouse over it and with keyboard focus](bilder/knoepfe-gefahr.png#only-light){ loading=lazy }
![Delete at rest with a border, red with the mouse over it and with keyboard focus](bilder/knoepfe-gefahr-dunkel.png#only-dark){ loading=lazy }

You recognise deleting, locking and similar actions by the **word** and the **icon**. The button only turns red when you point at it with the mouse or reach it with the keyboard – so nothing red catches your eye while you don't need it.

![Confirmation “Delete note?” with Cancel and a red Delete button](bilder/knoepfe-rueckfrage.png#only-light){ loading=lazy }
![Confirmation “Delete note?” with Cancel and a red Delete button](bilder/knoepfe-rueckfrage-dunkel.png#only-dark){ loading=lazy }

Before something is really gone, **Ablago always asks** and says what will happen. Only the red button in the question carries it out; **Cancel** or ++esc++ leaves everything as it was.

## When a button doesn't work { #gesperrt }

![Discard and Save faded while there is no change](bilder/knoepfe-blass.png#only-light){ loading=lazy }
![Discard and Save faded while there is no change](bilder/knoepfe-blass-dunkel.png#only-dark){ loading=lazy }

**Faded** means there is nothing to do right now – for example **Save** while you haven't changed anything. As soon as you change something, the button becomes strong.

![Delete folder dashed with a lock and ⓘ, above it the explanation why it is not possible right now](bilder/knoepfe-gesperrt.png#only-light){ loading=lazy }
![Delete folder dashed with a lock and ⓘ, above it the explanation why it is not possible right now](bilder/knoepfe-gesperrt-dunkel.png#only-dark){ loading=lazy }

**Dashed with a lock and ⓘ** means this is locked for you right now. A click on the button explains why – and often what you can do instead.

One exception: dashed **areas** that you can drag files onto are not locked – that is where you drop documents.

## Not a button: labels { #etiketten }

![Labels Text, New, Active, Warning and Error](bilder/knoepfe-etikett.png#only-light){ loading=lazy }
![Labels Text, New, Active, Warning and Error](bilder/knoepfe-etikett-dunkel.png#only-dark){ loading=lazy }

Small coloured marks **without a border**, such as **New** or **Warning**, are **labels**. They tell you something about a folder or an entry; clicking them does nothing.

## Switches and ticks { #schalter }

![Switch WebDAV drive, On](bilder/knoepfe-schalter.png#only-light){ loading=lazy }
![Switch WebDAV drive, On](bilder/knoepfe-schalter-dunkel.png#only-dark){ loading=lazy }

A **switch** turns something **lasting** on or off – a function that keeps running afterwards, for example the WebDAV drive. Next to it you see whether it is **On** or **Off**.

![Tick Reminder by email, ticked](bilder/knoepfe-haken.png#only-light){ loading=lazy }
![Tick Reminder by email, ticked](bilder/knoepfe-haken-dunkel.png#only-dark){ loading=lazy }

A **tick** chooses an **option** – for this one action or as a property of an entry. It only takes effect when you save or press the main button.
