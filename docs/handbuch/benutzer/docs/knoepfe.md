# So sehen Knöpfe aus

An der Form eines Knopfs erkennst du in Ablago, was er tut – ohne ihn auszuprobieren. Hier siehst du alle Arten auf einen Blick. Die Bilder stammen direkt aus Ablago; liest du das Handbuch in dunkler Darstellung, sind auch sie dunkel.

## Knöpfe { #knoepfe }

![Knöpfe: + Neu grün, Speichern blau, Abbrechen und Löschen mit Rand](bilder/knoepfe-arten.png#only-light){ loading=lazy }
![Knöpfe: + Neu grün, Speichern blau, Abbrechen und Löschen mit Rand](bilder/knoepfe-arten-dunkel.png#only-dark){ loading=lazy }

- **Blau gefüllt – der Hauptknopf:** das, was du hier vor allem tust, zum Beispiel **Speichern**. Meist gibt es nur einen davon.
- **Grün mit „+“ – Anlegen:** legt etwas Neues an. Dahinter steht, was entsteht, zum Beispiel **+ Vertrag** oder **+ Neu**.
- **Mit Rand – weitere Handlungen:** zum Beispiel **Abbrechen**, **Verwerfen** oder **Herunterladen**.

## Links { #links }

![Wege: + Neu, Als PDF herunterladen, die Links Zur Liste und Hilfe auf example.org](bilder/knoepfe-wege.png#only-light){ loading=lazy }
![Wege: + Neu, Als PDF herunterladen, die Links Zur Liste und Hilfe auf example.org](bilder/knoepfe-wege-dunkel.png#only-dark){ loading=lazy }

Blauer Text ohne Rand ist ein **Link**: Er führt woanders hin – auf eine andere Seite in Ablago oder nach draußen – und tut sonst nichts. Was etwas tut, ist immer ein Knopf.

## Gefährliches { #gefahr }

![Löschen in Ruhe mit Rand, mit der Maus darüber und mit Tastaturfokus rot](bilder/knoepfe-gefahr.png#only-light){ loading=lazy }
![Löschen in Ruhe mit Rand, mit der Maus darüber und mit Tastaturfokus rot](bilder/knoepfe-gefahr-dunkel.png#only-dark){ loading=lazy }

Löschen, Sperren und Ähnliches erkennst du am **Wort** und am **Symbol**. Rot wird der Knopf erst, wenn du mit der Maus darauf zeigst oder ihn mit der Tastatur erreichst – so springt dir nichts Rotes ins Auge, solange du es nicht brauchst.

![Rückfrage „Notiz löschen?“ mit Abbrechen und einem roten Knopf Löschen](bilder/knoepfe-rueckfrage.png#only-light){ loading=lazy }
![Rückfrage „Notiz löschen?“ mit Abbrechen und einem roten Knopf Löschen](bilder/knoepfe-rueckfrage-dunkel.png#only-dark){ loading=lazy }

Bevor etwas wirklich weg ist, **fragt Ablago immer nach** und sagt, was passiert. Erst der rote Knopf in der Rückfrage führt es aus; **Abbrechen** oder ++esc++ lässt alles, wie es war.

## Wenn ein Knopf nicht geht { #gesperrt }

![Verwerfen und Speichern blass, solange es keine Änderung gibt](bilder/knoepfe-blass.png#only-light){ loading=lazy }
![Verwerfen und Speichern blass, solange es keine Änderung gibt](bilder/knoepfe-blass-dunkel.png#only-dark){ loading=lazy }

**Blass** heißt: Gerade gibt es nichts zu tun – zum Beispiel **Speichern**, solange du nichts geändert hast. Sobald du etwas änderst, wird der Knopf kräftig.

![Mappe löschen gestrichelt mit Schloss und ⓘ, darüber die Erklärung, warum es gerade nicht geht](bilder/knoepfe-gesperrt.png#only-light){ loading=lazy }
![Mappe löschen gestrichelt mit Schloss und ⓘ, darüber die Erklärung, warum es gerade nicht geht](bilder/knoepfe-gesperrt-dunkel.png#only-dark){ loading=lazy }

**Gestrichelt mit Schloss und ⓘ** heißt: Für dich ist das gerade gesperrt. Ein Klick auf den Knopf erklärt, warum – und oft, was du stattdessen tun kannst.

Eine Ausnahme: Gestrichelte **Flächen**, auf die du Dateien ziehen kannst, sind nicht gesperrt – dort legst du Dokumente ab.

## Kein Knopf: Etiketten { #etiketten }

![Etiketten Text, Neu, Aktiv, Warnung und Fehler](bilder/knoepfe-etikett.png#only-light){ loading=lazy }
![Etiketten Text, Neu, Aktiv, Warnung und Fehler](bilder/knoepfe-etikett-dunkel.png#only-dark){ loading=lazy }

Kleine farbige Kennzeichen **ohne Rand**, etwa **Neu** oder **Warnung**, sind **Etiketten**. Sie sagen etwas über eine Mappe oder einen Eintrag; ein Klick darauf tut nichts.

## Schalter und Haken { #schalter }

![Schalter WebDAV-Laufwerk, An](bilder/knoepfe-schalter.png#only-light){ loading=lazy }
![Schalter WebDAV-Laufwerk, An](bilder/knoepfe-schalter-dunkel.png#only-dark){ loading=lazy }

Ein **Schalter** schaltet etwas **Dauerhaftes** an oder aus – eine Funktion, die danach weiterläuft, zum Beispiel das WebDAV-Laufwerk. Daneben steht, ob es gerade **An** oder **Aus** ist.

![Haken Erinnerung per E-Mail, angekreuzt](bilder/knoepfe-haken.png#only-light){ loading=lazy }
![Haken Erinnerung per E-Mail, angekreuzt](bilder/knoepfe-haken-dunkel.png#only-dark){ loading=lazy }

Ein **Haken** wählt eine **Option** – für diesen einen Vorgang oder als Eigenschaft eines Eintrags. Er wirkt erst, wenn du speicherst oder den Hauptknopf drückst.
