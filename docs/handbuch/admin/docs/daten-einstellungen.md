# Einstellungen zum Sichern

**Werkbank → Daten sichern → Einstellungen** sammelt dauerhafte Einstellungen, die für die ganze Ablage gelten. Sie standen früher mitten in den Abläufen – dort bleiben nur die Abläufe selbst: einen [Vollexport](export.md) starten und herunterladen, im [Papierkorb](papierkorb.md) wiederherstellen und leeren.

## Was Benutzer selbst dürfen { #was-benutzer-selbst-durfen }

**Benutzer dürfen ihre eigenen Daten exportieren** schaltet *Meine Daten exportieren* unter **Mein Konto → Konto** für alle Benutzer ein oder aus. Ab Werk ist es aus. Was der eigene Export enthält und was Benutzer sehen, solange er aus ist, steht unter [Meine Daten exportieren](export.md#meine-daten-exportieren).

Die Einstellung gilt für alle, auch in einem rein privaten Haushalt – darum steht sie hier und nicht unter Datenschutz.
