# Demo-Daten

Unter **Werkbank → Demo-Daten** füllst du ein DMS zum Ausprobieren oder Testen mit Inhalt.

![Demo-Daten](bilder/werkbank-demo.png)

## Beispiel-Mappentypen

**Beispiele laden** legt die Mappentypen *Vertragspartner*, *Vertrag*, *Rechnung* und *Zahlung* mit Feldern, Registern, Titel-Vorlagen und Trefferlisten an – dazu ein paar Mappen. Das ist ein guter Startpunkt, um eigene Typen daran anzulehnen.

Das geht nur, solange es außer *Benutzer* und *Rolle* noch keine Mappentypen gibt.

## Demo-Mappen erzeugen

Erzeugt beliebig viele Mappen (bis 5.000 auf einmal) für die vorhandenen Mappentypen – mit passenden Werten je Feld und Verweisen auf vorhandene Mappen. So lässt sich prüfen, wie sich Listen, Suche und Sortierung mit vielen Mappen verhalten.

Das läuft im Hintergrund; du kannst die Seite verlassen. Der Fortschritt steht auf dieser Seite.

Demo-Mappen sind gekennzeichnet. *Benutzer* und *Rolle* bekommen keine Demo-Mappen.

## Entfernen

**Demo-Mappen entfernen** löscht alle Demo-Mappen samt ihrer Dokumente. Echte Mappen bleiben unberührt. Verweist eine echte Mappe auf eine Demo-Mappe, wird nichts gelöscht – entferne dann zuerst diesen Verweis.

!!! tip "Ausprobieren ohne Risiko"
    Für Versuche mit größeren Änderungen an Mappentypen eignet sich eine zweite Installation mit eigener Datenbank besser als die echte.
