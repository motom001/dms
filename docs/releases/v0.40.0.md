## Neu

- **Neuer Bereich „Wie komme ich an ein DMS?“** (#179): Ein Wegweiser „Was hast du?“ führt zur passenden Anleitung, mit Badges zu Version, Sternen und Plattformen. Anleitungen gibt es für:
  - App-Store: umbrelOS, ZimaOS, CasaOS (bisher im Administratorhandbuch)
  - **Synology** mit Container Manager (#184)
  - **QNAP** mit Container Station (#185)
  - **UGREEN** mit Docker → Projekt (#181)
  - **TrueNAS** mit Custom App (#182)
  - **Unraid** mit Compose Manager (#183)
  - jeden Server mit Docker
- **Vorlagen mit nur einem Passwort:** Unter `deploy/` liegen eigene Compose-Vorlagen für Synology, UGREEN, QNAP, TrueNAS und Unraid. Das Passwort steht nur einmal ganz oben. Die Datenbank ist damit schon angebunden, und der Einrichtungsassistent überspringt den Datenbankschritt.
- **Neues Entwicklerhandbuch** (#180): Es erklärt, wie Mitarbeit läuft, nämlich User Stories, Freigabe durch den Maintainer und Pull Requests. Dazu kommen Abschnitte zum Loslegen, zum Aufbau, zum Einreichen eines Beitrags und zum Release. Neu sind außerdem `CONTRIBUTING.md`, eine Issue-Vorlage für Fehler und Links zu den Handbüchern beim Anlegen eines Issues.
- Die Startseite der Handbücher zeigt jetzt fünf Bereiche in der Reihenfolge des Lesers: Wofür ein DMS? → Wie komme ich an ein DMS? → Benutzerhandbuch → Administratorhandbuch → Entwicklerhandbuch.

## Für Administratoren

- Neue Umgebungsvariablen `DMS_DB_PASSWORT` und optional `DMS_DB_HOST` (Standard `db`) und `DMS_DB_PORT` (Standard `5432`). Sie ersetzen `DATABASE_URL` für die Standard-Anbindung, ohne Sonderzeichen für eine URL maskieren zu müssen. Wie `DATABASE_URL` zählen sie nur beim ersten Start.
- Die Seite „Installation auf dem NAS“ im Administratorhandbuch heißt jetzt **„Einrichtung und Betrieb“**. Sie beschreibt den Einrichtungsassistenten, die Datenbank-Anbindung, Ordner, Einstellungen und den Reverse-Proxy. Die Installation selbst steht im neuen Bereich.
- Das Label `freigegeben` vergibt nur der Maintainer. Setzt es jemand anderes, entfernt ein Workflow es wieder.
- Die CI installiert jede NAS-Vorlage probehalber mit dem gerade gebauten Image. Dabei prüft sie, dass der Assistent ohne Datenbankschritt beginnt.
