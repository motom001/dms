## Neu

- **Paketformat: Beispiele verweisen auf andere Beispiele** (#347). Beispiel-Mappen eines Pakets können jetzt zeigen, wie Mappen zusammenhängen – ein Vertrag auf seine Organisation, eine Zahlung auf ihren Vertrag.
  - Ein Beispiel bekommt optional einen `schluessel`; ein Verweisfeld darf `{ beispiel: strom }` sein, auf Beispiele einer Abhängigkeit `{ beispiel: "basis:stadtwerke" }`.
  - Das DMS legt die Beispiele in passender Reihenfolge an. Kreise, unbekannte Schlüssel und fremde Pakete ohne Abhängigkeit lehnt es beim Lesen mit verständlicher Meldung ab – es wird nichts halb installiert.
  - Wer die Beispiele mitinstalliert, bekommt auch die Beispiele der Abhängigkeiten, die dabei neu dazukommen. Ist eine Abhängigkeit schon ohne Beispiele da, bleiben Verweise darauf leer; die Vorschau sagt das.
  - Beim Update entstehen wie bisher keine Beispiele.
- Entwicklerhandbuch *Pakete entwickeln*: `schluessel` und `{ beispiel: … }`.
