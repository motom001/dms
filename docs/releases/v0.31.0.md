## Neu

- **Schlüssel am Mappentyp** (#145): Neben dem Namen hat jeder Mappentyp einen festen **Schlüssel** (z. B. `vertrag`). Er wird aus dem Namen vorgeschlagen, lässt sich beim Anlegen ändern und ist danach fest. So lässt sich ein Mappentyp umbenennen, ohne dass sprechende Links oder Skripte kaputtgehen.
- **Sprechende Links** nutzen den Schlüssel: `/ablage/link?typ=vertrag&…`. „Link kopieren“ erzeugt solche Links. Links mit dem Namen funktionieren weiter.

## Für Administratoren

- Beim ersten Start nach dem Update bekommt jeder Mappentyp einen Schlüssel aus seinem Namen; die Systemtypen heißen `benutzer`, `rolle` und `email`. Gibt es einen Schlüssel schon, wird eine Zahl angehängt (`rechnung_2`).
- Die API liefert den Schlüssel mit (`schluessel`) und nimmt ihn beim Anlegen entgegen.
