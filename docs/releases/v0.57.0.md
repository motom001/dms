## Neu

- **Auswahlfilter mit Werten der eigenen Mappe** (#173): Im Auswahlfilter eines Referenzfelds kann eine Bedingung den Wert eines Felds der eigenen Mappe nehmen, z. B. *Fachgebiet ist einer von* **Fachgebiet dieser Mappe**.
  - Nur Felder mit passendem Datentyp; nicht das Referenzfeld selbst. Das DMS prüft das beim Speichern des Mappentyps.
  - Die Auswahl folgt dem eigenen Feld sofort; passt eine gewählte Mappe nicht mehr, steht der Hinweis schon vor dem Speichern am Feld.
  - Leeres eigenes Feld: die Bedingung gilt nicht, alle anderen passenden Mappen werden angeboten.
  - Der Server prüft mit den Werten, die gespeichert werden – auch über die API.
