## Neu

- **Anmeldung über einen Anbieter per OpenID Connect** (#241) – z. B. Microsoft Entra ID (Microsoft 365), Google Workspace, Keycloak, Authentik, Authelia:
  - Einrichten unter **Werkbank → Anmeldeschutz**: Adresse des Anbieters, Client-ID, Client-Secret (verschlüsselt gespeichert), Beschriftung des Knopfes, **Verbindung prüfen**.
  - Knopf auf der Anmeldeseite; Fehler der Anmeldung stehen dort im Klartext.
  - Zuordnung über die E-Mail-Adresse; auf Wunsch **neue Benutzer anlegen** mit wählbarer Rolle.
  - **Rolle aus einer Gruppe** des Anbieters (Administratoren); der letzte Administrator bleibt Administrator.
  - **Passwort-Anmeldung nur noch für Administratoren** als Notzugang.
  - **Abmelden auch beim Anbieter** (RP-initiated Logout).
  - Sicher: Authorization Code Flow mit PKCE, state und nonce, an den Browser gebunden; das DMS prüft Signatur, Aussteller, Empfänger und Gültigkeit des ID-Tokens selbst (RSA, RSA-PSS, ECDSA, Ed25519). Keine neue Abhängigkeit.
