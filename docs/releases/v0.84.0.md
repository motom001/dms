## Neu

- **Archivnummer per Barcode-Aufkleber** (#345, Kernteil): Papieroriginal und Dokument verbinden.
  - Jedes **Dokument** kann eine Archivnummer haben (z. B. `A-000123`), eindeutig je Haushalt. Eintragen und ändern direkt an der Dokumentzeile; die Historie der Mappe hält Änderungen fest.
  - Neuer Nummernkreis **Archivnummer** (`A-{zaehler:6}`, in der Werkbank änderbar, nicht löschbar).
  - **Aufkleber drucken** (Werkbank → Nummernkreise → Archivnummer): PDF für A4-Etikettenbögen (48,5 × 25,4 / 38,1 × 21,2 / 70 × 37 mm), Startfeld für angebrochene Bögen, Barcode **Code 128** mit `DMS-ASN:` und lesbarer Nummer. Gedruckte Nummern gelten als vergeben.
  - **Suchen:** Archivnummer ins Suchfeld tippen oder mit dem Handscanner einscannen, Enter – das DMS öffnet die Mappe mit dem Dokument.
  - Aus dem Papierkorb wiederhergestellte Dokumente verlieren ihre Archivnummer, wenn sie inzwischen vergeben ist.
- Schnittstelle: `PUT /dokumente/{id}/archivnummer`, `GET /archivnummern/{nr}`; `archivnummer` am Dokument.
- Datenbank: Migration **038** (Spalte `archivnummer` an `dokumente`, eindeutig je Haushalt).
- Handbücher: *Dokumente → Archivnummer* (mit Tipp zum Ablageort), *Nummernkreise → Archivnummern und Aufkleber*.

## Noch nicht dabei

- QR-Code auf den Aufklebern (nur Code 128), eine Spalte „Archivnummer“ in Trefferlisten und das Erkennen der Aufkleber beim Scannen – das kommt mit dem Paket Trennblatt (dms-registry #16).
