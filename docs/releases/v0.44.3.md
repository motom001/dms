## Neu

- **Images mit Herkunftsnachweis und Stückliste** (#220): Jedes veröffentlichte Image (`dms` und `dms-komplett`) trägt einen signierten Nachweis, aus welchem Commit und mit welchem Workflow es gebaut wurde, und eine Stückliste (SBOM) aller enthaltenen Pakete. Prüfen mit `gh attestation verify oci://ghcr.io/motom001/dms:0.44.3 -R motom001/dms` – siehe Administratorhandbuch, *Aktualisieren*.
- **Images werden auf Sicherheitslücken geprüft** (#220): Vor jedem Merge prüft die CI beide Images auf bekannte Lücken in den Systempaketen und Bibliotheken; kritische Lücken, für die es eine Korrektur gibt, verhindern den Merge. Veröffentlichte Images werden ebenfalls geprüft (auch beim wöchentlichen Neubau), die Funde stehen öffentlich unter *Security* im Repository.

## Geändert

- Die Images enthalten kein npm, Yarn und Corepack mehr: Das DMS braucht sie zur Laufzeit nicht, und ihre mitgebrachten Bibliotheken waren die einzigen Funde der ersten Prüfung (#220).
- **Sicherheit sichtbar** (#221): Die README zeigt Abzeichen für CodeQL und die [OpenSSF Scorecard](https://scorecard.dev/viewer/?uri=github.com/motom001/dms) und einen Abschnitt *Sicherheit und Offenheit*. `SECURITY.md` listet, was wann automatisch geprüft wird.

## Für Entwickler

- GitHub Actions sind auf feste Commit-Kennungen gesetzt (Dependabot aktualisiert sie), Workflows haben oben nur Leserechte. Neuer Workflow *Scorecard*. Regeln und ein Vorschlag für ein Ruleset auf `main` stehen im Entwicklerhandbuch unter *Release*.
