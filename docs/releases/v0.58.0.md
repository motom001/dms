## Neu

- **Versionierung von Dokumenten** (#194):
  - Am Dokumentenregister in der Werkbank **Versionierung einschalten** (Standard: aus), optional „nur die letzten N Versionen behalten“.
  - **Ersetzen** legt eine neue Version an – auch mit anderem Namen oder Dateityp (z. B. JPG → PDF); die Mappe zeigt die neueste.
  - **Version 3** am Dokument: alle Versionen mit Datum, wer, Herkunft, Name und Größe; ansehen, herunterladen, **zurückholen** (als neue, höchste Version).
  - **Gleicher Dateiname** beim Hochladen: als neue Version, mit Zähler („Rechnung (2).pdf“) oder – ohne Versionierung – altes löschen. Über die API mit `gleicherName`, Standard „mit Zähler“.
  - Volltext und Suche beziehen sich auf die aktuelle Version. Löschen entfernt alle Versionen; der Papierkorb nimmt sie mit der Mappe mit.
  - Historie, Sicherung, Speicherplatz-Anzeige und API v1 (Versionen auflisten, herunterladen, ersetzen, zurückholen) sind dabei.

## Geändert

- Lädt man eine Datei mit einem Namen hoch, den es im Register schon gibt, bekommt sie jetzt einen Zähler, z. B. `Rechnung (2).pdf`.
