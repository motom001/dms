## Behoben

- **Paket-Läufer:** Schlägt das Update eines Pakets mit Code fehl, kommt jetzt auch der alte Code zurück – vorher lief die alte Version mit dem neuen Modul weiter. Bei einer gescheiterten Neuinstallation bleibt kein Code zurück (#403).
- **Werkbank → Pakete → *Paket*:** Direkt nach der Installation steht nicht mehr „Der Paket-Läufer läuft nicht“, sondern „startet …“ und dann „bereit – wartet auf das erste Ereignis“; die Seite fragt von selbst nach, bis der Läufer bereit ist (#403).

## Geändert

- **Größengrenze für Code:** Die Dateien unter `code/` (Modul, Daten, Quellcode) dürfen zusammen höchstens **32 MB je Paket** groß sein; größere Pakete lehnt das DMS mit klarer Meldung ab. Sie zählen nicht mehr zur allgemeinen Grenze von 20 MB für das entpackte Archiv (#403).
- **Paket-Läufer lädt nur Geändertes:** Wird ein Paket installiert, aktualisiert oder entfernt, liest der Läufer nur dessen Modul neu; die übrigen behalten ihr geladenes Modul (#403).
- **Zustand nach Absturz:** Stürzt der Läufer ab, zeigt die Werkbank „abgestürzt um … – startet neu …“ und danach „neu gestartet nach Absturz um …“ statt „startet …“. Das Admin-Handbuch (*Pakete → Pakete mit Code*) erklärt alle Zustände (#403).
