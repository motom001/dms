## Neu

- **Sprechende Links auf Mappen** (#98): Ein Link wie `/ablage/link?typ=Rechnung&rechnungsnummer=A-2020-11380` findet Mappen über ihren Mappentyp und ihre Angaben statt über die technische Id. Es gelten dieselben Operatoren und dynamischen Werte wie bei Sichtbedingungen, z. B. `bezahlt=nein`, `betrag.groesser=100`, `kuendigung_bis.zwischen=heute..heute+12monate`, `sortierung=-rechnungsdatum`. Ein Treffer öffnet die Mappe; bei mehreren erscheint die Trefferliste als vorübergehende Sicht, und die erste Mappe ist geöffnet. Fehler im Link meldet das DMS deutlich. Beschrieben im [Administratorhandbuch](https://motom001.github.io/dms/admin/direktlinks/).
- **Aktionen → Link kopieren** in jeder Mappe: baut den Link aus einer eindeutigen Angabe (sonst aus den Titelfeldern) und legt ihn in die Zwischenablage.
- Über die Schnittstelle: `GET /api/v1/mappen?sicht=link&link=…`.

## Beim Aktualisieren beachten

- Links nennen den Mappentyp beim Namen: Wer einen Mappentyp umbenennt, macht alte Links ungültig.
