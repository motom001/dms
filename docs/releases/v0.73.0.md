## Neu

- **Neue Wörter in Oberfläche, Handbüchern, Hilfe und Glossar** (#305). Jedes Ding im DMS hat jetzt ein eindeutiges, alltagsnahes Wort – überall dasselbe. Es ändert sich nur, was du liest: Daten, Links, die Schnittstelle (`/api/v1`) und Pakete funktionieren unverändert weiter.

| bisher | jetzt |
| --- | --- |
| Eingang (Liste deiner Aufgaben) | **Zu erledigen** – der *Eingangsordner* für den Scanner heißt weiter so |
| Sicht, Sichten, Untersicht | **Ansicht**, Ansichten, Unteransicht |
| Profil: „Ansicht auf diesem Gerät“ | **Darstellung auf diesem Gerät** |
| Pakete: „Erweiterte Ansicht“ | **Expertenmodus** |
| Register „Protokoll“ einer Mappe | **Historie** – *Werkbank → Protokoll* (Betriebsprotokoll) bleibt |
| Schlüssel eines Felds, Registers, Mappentyps oder Nummernkreises | **Kennung** – der Schlüssel der Verschlüsselung und API-Schlüssel bleiben |
| Feldart „Referenz“, Referenzfeld | **Verweis**, Verweisfeld |
| Datentyp eines Felds | **Feldart** |
| Typ (allein) | **Mappentyp** |
| Direktlink, sprechender Link | **Link** (z. B. „Link über Mappentyp und Feldwerte“) |
| Werkbank → Fehlermeldungen | **Gemeldete Fehler** |
| Vertretung beenden / Zurück zu meinem Konto | **Zurück zum eigenen Konto** |
| Persönlicher Export | **Meine Daten exportieren** |
| Mandant | **Haushalt** |
| Rolle (Administrator/Mitglied) und „Weitere Rollen“ | **Systemrolle** (Administrator, Mitglied) und **Rollen** (Gruppen wie „Eltern“) |
| Aufgabenart „Aufgabe“ | **Zugewiesen** (Oberbegriff bleibt „Aufgabe“) |
| Aufgabenart „Neue Post“ | **Post für dich** – die Ansicht „Neue Post“ bleibt |

- **Glossar:** Die entschiedenen Fragen stehen auf der Seite „Begriffe“ jetzt unter „Entschieden“; die alten Wörter unter „nicht verwenden“. Neu sind die Begriffe *Kennung* und *Systemrolle*.
- **Handbuch Schnittstelle:** Ein Kasten erklärt, welche API-Namen welchen Wörtern der Oberfläche entsprechen (`sicht` = Ansicht, `sicht=eingang` = Zu erledigen, `key` = Kennung, `referenz` = Verweis …).

## Beim Aktualisieren beachten

- Register der Art „Protokoll“, die noch den alten Standardnamen tragen, heißen nach dem Update **Historie** (Migration 036). Selbst vergebene Namen bleiben.
- Adressen der Handbuchseiten bleiben gleich; einige Überschriften haben neue Anker (z. B. *Die Kennung*, *Verweise: Mappen verbinden*, *Gemeldete Fehler*, *Historie*).
