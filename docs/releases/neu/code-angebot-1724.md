## Neu

- **Daten abrufen beim Ausfüllen** (#1724): Ein Paket kann zu einem Code auf dem Dokument Daten anbieten – etwa *Fahrzeuge – KBA* zum QR-Code auf dem HU-Bericht. Im vorhandenen Hinweis „… Felder als Vorschlag eingetragen – bitte prüfen“ erscheint dann ein Knopf wie „Daten beim KBA abrufen“ mit dem Namen des Pakets. Erst der Klick ruft das Paket; die Werte kommen als Vorschläge mit „Zurücknehmen“, was du selbst geändert hast, bleibt stehen. Für Paketentwickler: `code.angebote` im Manifest.
