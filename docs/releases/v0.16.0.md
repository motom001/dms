## Neu

- **Dokumente ansehen mit einem Klick auf die Zeile** (#85): Ein Klick irgendwo auf die Zeile eines PDFs oder Bilds zeigt es **direkt unter dieser Zeile** an und scrollt dorthin; ein zweiter Klick schließt es. Es ist immer nur eins offen. „Öffnen“ ist ersetzt durch das Symbol **↗** (in neuem Tab). Knöpfe und Links in der Zeile tun weiter, was sie sollen.
- **Dokumente sortieren** (#86): Name A–Z (natürlich, „2“ vor „10“), Name Z–A, neueste, älteste, größte zuerst. Gemerkt je Benutzer für alle Dokumentenregister.
- **Mehrere Dokumente auswählen** (#87): Kästchen je Zeile, „Alle auswählen“, Umschalt + Klick für Bereiche. Die Auswahl lässt sich gemeinsam **herunterladen** (einzeln nacheinander) oder zum **Löschen** vormerken – gelöscht wird wie bisher mit „Mappe speichern“.
