## Sicherheit

- **Erweiterte Suche: Parameternamen abgesichert** (#292, Schwere: hoch). Ein angemeldeter Benutzer konnte über einen präparierten Link der erweiterten Suche Eigenschaften aller Objekte im Serverprozess verändern („Prototype Pollution“) und das DMS damit bis zum nächsten Neustart für alle stören. Die Suche verwirft solche Namen jetzt; ein Test prüft genau diesen Fall. Betroffen waren die Versionen 0.62.0 bis 0.71.0 – bitte aktualisieren.
