- **Vollexport aller Daten in offenen Formaten** (#254) – kein Vendor-Lock-in. **Werkbank → Vollexport**:
  - Ein Ordner neben den Sicherungen (`export/`), lesbar ohne das DMS: `LIESMICH.md`, `manifest.json` mit SHA-256 jeder Datei, Struktur (Mappentypen, Sichten, Nummernkreise, Designs, Benutzer ohne Passwörter), je Mappentyp CSV (RFC 4180, Komma, UTF-8 mit BOM), JSON Lines und Excel, Verweise, Dokumentliste, Notizen, Aufgaben, Erinnerungen, Historie, Papierkorb, Favoriten, Vertretungen.
  - `ablage/<Typ>/<Titel> [Id]/` mit `mappe.json`, `mappe.pdf`, den Dokumenten im Original, erkanntem Text und allen älteren Versionen.
  - PDF-Übersicht je Typ, Kalender (`fristen.ics`), Kontakte als vCard 4.0 (Zuordnung vom Administrator bestätigt).
  - Passwörter nur mit ausdrücklicher Bestätigung als `passwoerter.csv` (Bitwarden-Format); technische Protokolle wählbar.
  - Abschätzung von Größe und freiem Platz, Auftrag im Hintergrund, als ZIP herunterladen, **Prüfen** gegen das Manifest, Löschen.
  - Ein Test schlägt fehl, wenn eine Tabelle der Datenbank im Export fehlt.
  - Neue Seite **Daten exportieren** im Administratorhandbuch.
