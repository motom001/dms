## Technik

- **Neue Abhängigkeiten nur mit Begründung** (#543): Das DMS kommt mit wenig fremdem Code aus, und so soll es bleiben. Eine neue Laufzeit-Abhängigkeit – ein npm-Paket oder ein Alpine-Paket im Image – braucht im Pull Request eine Begründung: wozu, warum nicht mit Bordmitteln, Lizenz, Pflegezustand und was sie selbst mitbringt. Die Regel steht in `CONTRIBUTING.md` (deutsch und englisch), die Vorlage für Pull Requests fragt danach.
  - Die Prüfung „Abhängigkeiten“ weist im Pull Request auf neue Laufzeit-Abhängigkeiten hin, ohne ihn zu sperren.
  - Das Entwicklerhandbuch listet unter *Aufbau → Abhängigkeiten* alle heutigen Abhängigkeiten mit Lizenz und Zweck.
