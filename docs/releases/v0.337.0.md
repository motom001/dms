## Neu

- **Feld aus einem QR-Code füllen** (#1723): Ist ein Paket installiert, das Codes liest (neues Recht `dms:codes`, z. B. „QR-Code lesen“), merkt sich Ablago die QR-Codes und Barcodes eines Dokuments einmal beim Eingang. „Aus Dokument ausfüllen“ trägt den passenden Code in Felder mit der neuen Erkennungsart „Code auf dem Dokument“ ein – etwa den Link zum Digitalen Untersuchungsbericht auf dem HU-Bericht, mit der Fundstelle „QR-Code auf Seite 1“. Ohne ein solches Paket ändert sich nichts.
