## Neu

- **Paket-Läufer: Recht nur für Post** (#435): Pakete mit Code können in `code.rechte` jetzt `dms:post` angeben statt aller Mappentypen (`"*"`). Mit `lesen`/`schreiben: ["dms:post"]` darf ein Paket Post lesen, teilen und die Archivnummer und den Volltext ihrer Dokumente setzen – andere Mappen sieht es nicht. Die Rechte-Rückfrage bei der Installation zeigt „Post“. Erstes Paket damit: **Trennblatt** 1.0.1.
- Unbekannte Kennungen `dms:…` in `code.rechte` lehnt das DMS jetzt beim Installieren mit einer klaren Meldung ab (bisher wurden sie stillschweigend ignoriert). Erlaubt sind `dms:ablageort`, `dms:rolle` und `dms:post`.
- Entwicklerhandbuch *Pakete mit Code → Im Manifest*: `dms:post` mit Beispiel.
