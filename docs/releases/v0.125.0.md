## Neu

- **Aus Dokument ausfüllen per Paket** (#511): Statt der eingebauten Erkennung kann ein Paket mit dem neuen Recht „Felder aus Dokumenten vorschlagen (`dms:erkennen`)“ die Felder vorschlagen – etwa ein KI-Assistent, der auch Freitext, Briefköpfe und schwierige Belege versteht. Die eingebaute Erkennung bleibt der Standard.
  - Wahl in der Werkbank am Paket (**als Standard für alle Mappentypen**) und je Mappentyp unter **Erkennung** (Standard, eingebaut oder ein Paket).
  - Ein Paket, das ins Netz darf, nur mit ausdrücklicher Bestätigung des Datenabflusses.
  - Das Paket bekommt den Text und die Beschreibung der Felder (JSON Schema) – nie Passwortfelder, nie Felder, die du nicht bearbeiten darfst, keine Verweise. Jede Antwort prüft das DMS gegen die Feldarten; Verworfenes steht im Protokoll. Alles bleibt Vorschlag.
  - Antwortet das Paket nicht (60 Sekunden) oder unbrauchbar, übernimmt die eingebaute Erkennung, mit Hinweis. Unter dem Ergebnis steht, womit erkannt wurde.
- Schnittstelle: `POST /typen/{id}/vorschlaege` liefert zusätzlich `engine` und ggf. `hinweis`; `GET`/`PUT /api/werkbank/erkennung`.

## Handbuch

- Administratorhandbuch: Pakete → Recht „Felder aus Dokumenten vorschlagen“, Erkennung durch ein Paket; Mappentypen → Erkennung.
- Benutzerhandbuch: Mappen → Aus Dokument ausfüllen.
- Entwicklerhandbuch: Pakete mit Code → Erkennung als Paket (`dms:erkennen`).
