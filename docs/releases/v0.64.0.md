## Neu

- **Paketverwaltung: erweiterte Ansicht** (#189) – für Paketentwickler und DMS ohne Internetzugang. **Werkbank → Pakete → Erweiterte Ansicht** (je Benutzer, standardmäßig aus):
  - **Weitere Katalogadressen** hinzufügen, abschalten und entfernen (nur HTTPS, gleiches Format). Pakete daraus tragen ihre Quelle.
  - **Paket als Datei hochladen** (`.zip` im Format der Registry) – dieselbe Prüfung wie bei Katalogpaketen, ohne Prüfsumme aus dem Katalog.
  - Vor der Installation aus einer anderen Quelle als dem offiziellen Katalog eine deutliche Warnung („nicht vom DMS-Projekt geprüft“), die man ausdrücklich bestätigen muss.
  - Installierte Pakete zeigen ihre **Herkunft**; Updates kommen nur aus dieser Quelle. Ein hochgeladenes Paket aktualisiert man durch erneutes Hochladen einer höheren Version.
  - Das Protokoll vermerkt Quellen und Uploads.
  - In der normalen Ansicht bleibt es beim offiziellen Katalog.
  - Administratorhandbuch (Pakete → Erweiterte Ansicht), Entwicklerhandbuch („Eigenes Paket testen“).
