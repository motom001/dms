## Neu

- **PDF bearbeiten** (#335): Seiten drehen, löschen, umsortieren, teilen und PDFs zusammenfügen – direkt im DMS, ohne anderes Programm.
  - **Seiten** neben einem PDF zeigt jede Seite als kleines Bild. Je Seite: um 90° drehen, löschen, verschieben (Knöpfe, Ziehen oder Alt + Pfeiltaste), **Teilen ab hier**. Erst **Übernehmen** speichert.
  - Mit Versionierung wird das Ergebnis eine **neue Version** – das Original bleibt erhalten, auch im Archivmodus. Ohne Versionierung ersetzt es das Dokument nach Rückfrage; das bisherige kommt in den Papierkorb.
  - **Teilen** in einer Mappe: Teil 1 wird die neue Version, die weiteren Teile eigene Dokumente „Name (Teil 2).pdf“ … im selben Register.
  - **Sammelscan teilen**: bei einer Post entsteht je Teil eine neue Post (Stand Neu, Betreff „… (Teil n)“). Die Ausgangspost behält das ganze PDF, ist erledigt und verweist auf die neuen.
  - **Zusammenfügen** für zwei oder mehr ausgewählte PDFs: ein neues Dokument im selben Register, die Ausgangsdokumente auf Wunsch in den Papierkorb.
  - Texterkennung und Vorschaubild laufen für die Ergebnisse neu; die Historie zeigt „PDF bearbeitet“ bzw. „Post geteilt“.
  - Alles mit pdf-lib im Server; Seiten werden kopiert, nicht neu berechnet – Text, Schriften und Bildqualität bleiben.
- **Schnittstelle**: `GET /dokumente/{id}/seiten`, `GET /dokumente/{id}/seiten/{nr}/bild`, `POST /dokumente/{id}/seiten` (drehen, Seiten löschen, umsortieren, teilen – bei Post „Post teilen nach Seitenbereichen“) und `POST /dokumente/zusammenfuegen` (auch aus mehreren Posts; eine dadurch leere Post wird erledigt). Damit können Pakete, z. B. für Barcode-Trennblätter, dieselben Schritte ausführen.
- Benutzerhandbuch: *Dokumente → PDF bearbeiten*, *Post → Sammelscan teilen*; Hilfe-Verweis in der Seitenansicht.
