## Neu

- **Paket per Link installieren** (#191): Die Adresse `/werkbank/pakete?installieren=<paket>@<version>` öffnet die Paketverwaltung mit der Vorschau genau dieses Pakets.
  - Das DMS holt Paket und Prüfsumme selbst aus dem offiziellen Katalog; andere Quellen im Link zählen nicht. Fehlt Paket oder Version, gibt es eine verständliche Meldung.
  - Installiert wird erst nach Klick auf „Installieren“. Ist das Paket schon installiert, zeigt die Vorschau das und bietet ggf. das Update an.
  - Ohne Anmeldung kommt zuerst die Anmeldung (auch über einen Anmeldedienst), danach geht es zurück zur Vorschau. Andere Benutzer sehen, dass nur Administratoren Pakete installieren.
- **Paketkatalog als Webseite** (motom001/dms-registry): Pakete ansehen wie im App Store, mit „In meinem DMS installieren“. Neue Karte **Paketkatalog** auf der Startseite der Handbücher.
- Administratorhandbuch: Pakete → Über die Katalog-Webseite.
