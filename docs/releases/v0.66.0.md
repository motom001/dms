## Neu

- **Paket-Einstellungen** (#197): Pakete beschreiben ihre Einstellungen im Manifest, das DMS baut daraus ein Formular. **Werkbank → Pakete → *Paket* → Reiter „Einstellungen“**:
  - Abschnitte mit Feldern und Listen gleich aufgebauter Einträge (hinzufügen, löschen, sortieren); höchstens zwei Ebenen.
  - Feldtypen wie bei den Mappentypen, dazu Verweise auf Mappentyp, Feld, Benutzer, Rolle und Sicht (gespeichert wird die Id) und **Geheimnisse**, verschlüsselt mit dem Schlüssel des DMS und nach dem Speichern nie mehr angezeigt.
  - Prüfung beim Speichern mit Fehlern am Feld; Aktionen als Knöpfe mit Zeitgrenze; schreibgeschützter Status des Pakets.
  - Installieren setzt Vorgaben („Einstellungen nötig“, solange Pflichtfelder fehlen); ein Update ergänzt neue Felder und entfernt wegfallende (die Vorschau nennt sie); Entfernen fragt, ob die Einstellungen bleiben sollen.
  - Teil der Sicherung, beim Schlüsselwechsel umgeschlüsselt; Protokoll ohne Werte von Geheimnissen; nicht über die API v1 lesbar.
  - Pakete mit Code lassen sich installieren und einstellen; ihr Code läuft erst mit dem Paket-Läufer.
  - Format: motom001/dms-registry (Schema, Prüfung, Vorlage). Administrator- und Entwicklerhandbuch ergänzt.
