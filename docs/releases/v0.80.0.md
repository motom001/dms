## Neu

- **Startseite mit wenigen Kacheln** (#334). Nach der Anmeldung öffnet die Ablage mit **Start**: je eine Kachel mit einer Zahl und einem Klick für **Zu erledigen**, **Neue Post**, **Anstehend** und – wählbar – **Favoriten** oder eine Ansicht. Darunter die **zuletzt geöffneten** Mappen; ein Klick öffnet sie rechts daneben.
  - Leere Kachel = grünes Häkchen („✓ Nichts zu erledigen“) statt einer Null; *Zu erledigen* ist hervorgehoben, solange es etwas zu tun gibt. Alle Zahlen beachten die Berechtigungen.
  - In einer leeren Ablage drei Einstiege: *Erste Post ablegen*, *Paket Haushalt installieren* (Administratoren), *Hilfe: so fängst du an*.
  - Im **Profil → Startseite**: abschalten (dann direkt zu *Zu erledigen*) und die vierte Kachel wählen.
  - „Zuletzt geöffnet“ merkt sich das DMS je Benutzer (höchstens zehn, angezeigt fünf, nur lesbare). Zugriffe über API-Schlüssel zählen nicht.
- Benutzerhandbuch: neue Seite *Startseite*, Abschnitt im *Profil*; Hilfe-Symbol auf der Startseite.
