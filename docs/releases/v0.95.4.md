## Behoben

- **Paket-Rechte verständlich** (#449): In der Vorschau vor der Installation eines Pakets mit Code steht statt „kein Netz“ jetzt **„kein Zugriff auf Netzwerk und Internet“** bzw. **„Zugriff auf Netzwerk/Internet nur zu: …“**. Die Ereignisse stehen unter **„Reagiert auf diese Ereignisse:“** als eigene Liste, ein Ereignis je Zeile. Hinter jedem Recht und jedem Ereignis führt ein **?** zur Erklärung im Administratorhandbuch (Pakete → Pakete mit Code → Rechte eines Pakets bzw. Ereignisse – dort neu: wann jedes Ereignis kommt und was ein Paket typischerweise damit macht).
- Der Haken **„Ich erlaube dem Paket diese Rechte.“** (beim Update „Die Rechte haben sich geändert. Ich erlaube sie.“) steht jetzt links **unter** der Liste statt rechts daneben – erst lesen, dann bestätigen; am Handy ebenso.
