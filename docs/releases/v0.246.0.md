## Neu

- **Pakete mit dem echten Installer prüfen** (#1124): Der Befehl `pakete-pruefen` im Image installiert Paketordner mit dem Installer dieser Version in eine leere Ablage im Arbeitsspeicher – mehrere Pakete in Abhängigkeitsreihenfolge, auch als Update von einer älteren Version – und nennt je Paket OK oder die Gründe; ohne Datenbank-Server und ohne Netz, z. B. `docker run --rm -v "$PWD/pakete:/pakete:ro" ghcr.io/motom001/dms:<version> pakete-pruefen /pakete`. Für die CI von dms-registry und für eigene Pakete; Anleitung im Entwicklerhandbuch unter „Pakete mit Ablago prüfen“. Ablago prüft so auch selbst in jedem Pull Request die Pakete aus dem Katalog gegen den eigenen Stand (als Warnung).
