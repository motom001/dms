## Sicherheitsupdate – bitte aktualisieren

Behebt sechs Funde der Code-Analyse (CodeQL, #250). Keiner ist ohne Anmeldung als Administrator ausnutzbar; das Update wird trotzdem empfohlen.

- **Eigenes CSS eines Designs:** Ein präpariertes CSS konnte den Filter für `<style>` umgehen. Jetzt ist das Zeichen `<` im eigenen CSS nicht mehr erlaubt (in Texten geht `\3C `), und bei der Anzeige wird es zusätzlich maskiert. Ein bestehendes Design mit `<` im CSS wirkt weiter, lässt sich aber erst nach dem Entfernen wieder speichern.
- **Logo als SVG:** Die Erkennung eines SVG ließ sich mit sehr vielen Kommentaren stark verlangsamen. Sie kommt jetzt ohne den anfälligen regulären Ausdruck aus.
- **Einrichtungsmodus:** `/api/gesundheit` rechnet nichts mehr je Anfrage. Der Einrichtungscode bleibt wie bisher nach zehn Fehlversuchen zehn Minuten gesperrt.
- **Kleinere Maskierungen:** Werkbank → Technik → *Als Text kopieren* maskiert auch Backslashes, der Versionsabgleich kodiert Paketnamen vollständig, die Hilfe-Prüfung der CI maskiert Anker vollständig.
