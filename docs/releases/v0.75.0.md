## Neu

- **Pakete können auf Mappentypen des DMS verweisen** (#310), für alle, die Pakete schreiben: `dms:ablageort` für den Ablageort (z. B. das Feld *Verbleib Originaldokumente*), außerdem `dms:benutzer` und `dms:rolle`. So bringen die kommenden Pakete Haushalt, Haus und Fahrzeuge keinen eigenen Ablageort mit, sondern nutzen den, den jedes DMS hat.
  - Die Paket-Vorschau zeigt diese Verweise als „Ablageort (aus dem DMS)“.
  - Unbekannte `dms:…`-Verweise und die Paket-Id `dms` lehnt das DMS schon beim Lesen ab; fehlt ein Typ, meldet die Vorschau, ab welcher Version das DMS ihn kennt.
  - Entwicklerhandbuch *Pakete entwickeln* beschreibt die neue Form; Schema und Prüfwerkzeug im Paketkatalog kennen sie ebenfalls.
