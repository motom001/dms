## Neu

- **Sichten verwalten** (#38): unter *Werkbank → Sichten* festlegen, was die Ablage links anbietet
  - eine oder mehrere Mappentypen je Sicht; bei mehreren verhält sich die Liste wie der Eingang
  - **Baum** beliebiger Tiefe: Untersichten zum Auf- und Zuklappen; eine Sicht zeigt auch alles ihrer Untersichten
  - neue Mappentypen bekommen auf Wunsch eine eigene Sicht
- **Bedingungen auf Feldwerte** (#40): ist gleich, enthält, kleiner, größer, zwischen, außerhalb, im Zeitraum, ist einer von, zeigt auf, leer/nicht leer – auch auf *angelegt/geändert am/von*
  - **dynamische Werte**: heute ± n Tage/Wochen/Monate/Jahre, aktuelles Jahr/aktueller Monat ± n, aktueller Benutzer, Rollen des aktuellen Benutzers – z. B. „Kündigung in den nächsten 12 Monaten“ oder „Meine Verträge“
- **Bedingungen auf die Anzahl** von Dokumenten oder Verknüpfungen in einem Register (#41) – z. B. „Rechnungen ohne Beleg“
- Vorschau der Trefferzahl beim Bearbeiten einer Sicht; Bedingungen auf entfernte Felder werden markiert statt die Sicht zu leeren
- Schnittstelle: `GET /api/v1/sichten/definitionen`; `GET /api/v1/mappen?sicht=typ:<Id>` liefert alle Mappen eines Typs

## Beim Aktualisieren beachten

- Die bisherigen Sichten (eine je Mappentyp) werden automatisch übernommen; Adressen, Lesezeichen und gemerkte Sortierungen bleiben gültig.
